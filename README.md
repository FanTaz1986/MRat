# MRat

A browser-based game project.

## 🚀 Getting Started

### 1. Clone the Repository

```sh
git clone https://github.com/FanTaz1986/MRat.git
cd MRat
```

### 2. Install Dependencies

Make sure you have [Node.js](https://nodejs.org/) installed. Then run:

```sh
npm install
```

### 3. Start the Game

Start the development server with:

```sh
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser to play.

---

## 🎮 Basic Game Controls

- **Movement:** Use the arrow keys (`←`, `↑`, `→`, `↓`) to move your character.
- **Interact:** Use the `Spacebar` to enter a portal when standing on it.
- **Camera:** The camera follows your character automatically.
- **Portals:** Stand on a portal tile and press `Spacebar` to teleport to another map area.
- **Debug Info:** Some debug overlays may be visible during development.

---

## 🗺️ Game Overview

- The game features multiple maps with tile-based movement and portals connecting different areas.
- Props and obstacles are randomly generated for variety.
- Explore, find portals, and move between maps!
